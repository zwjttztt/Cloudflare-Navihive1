# 记事本（NotesPage）后续改造方案 —— 对标 inkstone

> 数据全部来自 2026-10-05 在真实 Chrome 里对 `note.zwjttzt.com` 的实测
> （视口 1360×700），不是看截图估的。实测脚本：`harness/ink-cols.mjs` / `harness/ink-probe.mjs`。

## 一、先回答「右边是否显示不全」

**没有截断。** 在 1360 / 1200 / 1024 / 900 四档宽度上量预览栏：

| 视口宽 | 源码区 | 预览区 | 预览栏 `scrollW-clientW` |
| --- | --- | --- | --- |
| 1360 | 300..825 | 300..1350 | **0** |
| 1200 | 300..745 | 300..1190 | **0** |
| 1024 | 300..657 | 300..1014 | **0** |
| 900 | 300..595 | 300..890 | **0** |

唯一超出右边界的是主站背景装饰 `nav-aurora`（超出 132~173px），它被 body 的
`overflow-x: clip` 裁掉，不影响任何内容。

顺带确认：整页滚动条已经没了（记事本里 `innerWidth - clientWidth = 0`，
关掉记事本后恢复到 10px）。

## 三、改造方案（分四阶段，按风险从小到大）

### 阶段一：不碰数据，纯前端（建议先做，约 1~2 小时）

1. **工具栏改图标 + 分组**（最高性价比）
   15 个文字按钮 → 图标按钮（MUI `FormatBold` / `FormatItalic` / `Code` …），
   按 inkstone 的分法分组并用竖线隔开：
   标题（H1/H2/H3）｜强调（B I S 高亮）｜代码（行内 `<>` / 代码块 `{}`）｜
   列表（• 1. ☑）｜插入（🔗 🖼）｜块（引用 ❝ == 表格 |）。
   单行放得下、高 36px，和 inkstone 一致。
2. 加 **「标题层级」下拉**（H1/H2/H3），对齐 inkstone 工具栏第一项。
3. **左栏加导航区**：所有笔记／最近编辑／收藏／回收站。
   「收藏」复用现有 `pinned`；其余三个先做成有内容的视图
   （「最近编辑」按 `updated_at` 倒序，现有数据就够）。
4. **状态栏对齐**：左下「N 字 · 约 N 分钟读完」，右下「创建于 …」；
   删除/置顶图标化挪到顶栏右侧（现在是挤在状态栏右下，容易误触）。
5. 顶栏补 **回收站入口**、导出/导入 Markdown 图标。

### 阶段二：布局细节

6. 左栏可折叠（196px ↔ 9px 拖拽条），照搬 inkstone 的 `shrink-0 + transition-[width]`。
7. 列表按月份分组（「十月」「九月…」），条目统一 30px 高、hover/选中态对齐 inkstone。
8. 搜索框左侧加 `⌘` 提示（对应 inkstone 的 `Ctrl Shift F` 全局搜索），保持现有位置。

### 阶段三：要动数据（`SCHEMA_VERSION` 4，务必跟着升版本）

9. **回收站**：现在删除按钮的 tooltip 写着「可从回收站还原」，但**回收站根本没做**，
   这句话是假的。改成软删（`deleted_at`），加回收站视图 + 「清空回收站」。
10. 文件夹 / 标签 / 归档：`notes` 加 `archived`，新建 `folders`、`tags`、`note_tags` 三张表 + 迁移。
11. 「未归类」= `site_id IS NULL` 的自然结果，不用加水字段。

### 阶段四：编辑能力（阶段三之后再上，避免一次迁移塞太多）

12. 代码块语言下拉、表格增删行列、公式 —— 预览层已能渲染，只差工具栏入口。
13. 相对时间（「1分钟前」）替代现在的 `formatWhen`（今天给 HH:MM、更早给 M月D日）。
14. 自动保存：现在要手点保存 + 提示「有未保存的改动」；可考虑 debounce 3s 自动存
    （配合右下角「已保存 · 刚刚」的状态指示，与 inkstone 的同步图标一个意思）。

## 四、每阶段的验收方式

不许再靠猜。改完用 `harness/ink-*` / `harness/verify-*` 那套在真实 Chrome 里量：

- `node harness/ink-login.mjs https://note.zwjttzt.com harness/ink-cols.mjs harness/ink.png`（抄 inkstone）
- `W=1360 H=700 node harness/drive.mjs https://myhp.zwjttzt.com harness/verify-toggle.mjs harness/x.png`（验自己）

关键判据（见 `harness/browser-layout-measure` 那套方法）：
滚动条看 `innerWidth - documentElement.clientWidth`，**不要**看 `scrollHeight - clientHeight`
（`overflow:hidden` 下会虚报），也**不要**用 `scrollTo` 后看 `scrollY`（hidden 只是不给滚动条，脚本照样能滚）。

## 五、已知待改进（本轮没做的）

- 全选一整行再点「粗体」，若该行末尾不是干净的闭合标记（如 `**粗体***斜体*` 结尾是个单 `*`），
  会走「包一层」而不是「摘标记」，结果标记翻倍。嵌套标记场景的判定要再细一轮。
